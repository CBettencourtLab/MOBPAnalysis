# MOBPAnalysis

Code used for analyses investigating the MOBP locus across neurodegenerative diseases.

## Repository contents

### GWAS analyses
- `GWAS Correlation Analysis and COLOC.Rmd` — comparison of genetic association signals and colocalisation analyses.
- `SuSiE Colocalisation GWAS.Rmd` — SuSiE fine-mapping and colocalisation of GWAS signals.

### QTL analyses
- `eQTL COLOC` — eQTL colocalisation analyses.
- `mQTL COLOC and SuSiE` — mQTL colocalisation and SuSiE analyses.
- `pQTL COLOC` — pQTL colocalisation analyses.

### Genotype, methylation and transcript usage
- `TranscriptUsage_genotype_DNAm Analysis` — analysis of genotype, DNA methylation and MOBP transcript usage.

### RNA-seq processing
- `star_alignment_setup.sh` — STAR alignment setup.
- `star_allignment_array.sh` — STAR alignment array job.
- `slurmSub_bam_junc.sh` — SLURM script for BAM/junction processing.
